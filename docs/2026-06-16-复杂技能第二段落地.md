# 复杂技能模块 — 第二段落地

## 本轮需求

落实 `docs/九宫牌局复杂技能模块三段开发计划.md` 第二段，优先补齐正式牌组已接入怪物技能，并把登场/战斗类能力继续迁移到统一触发管线。

## 对齐权威文档

- 对齐：`04-技能/怪物技能.md`
- 对齐：`07-数据/怪物卡数据.md`
- 对齐重点：移动计数类、棋盘操作类、生成/移除类、光环/条件类、自动战斗类

## 实现要点

1. `SkillRuntime` 扩展为统一处理：
   - `onEnter`
   - `onCombat`
   - `onMoveEveryN`
   - 技能位移全局监听（用于 `灼热观察`）
   - 相邻光环动态刷新（离开相邻即失效）
2. `BattleResolver` 的战斗技能判定迁入 `processCombatSkillEffects`，降低硬编码分散度。
3. `BoardActionResolver` 在移动链中加入：
   - 技能位移全局副作用
   - 移动后光环重算
4. `TestData` 补充第二段目标中的正式牌组技能映射（如：丐帮同心、东西归我了、吞石、发装备了、不稳定、爱好旋转、乱步、献祭、呼唤信徒、灼热观察等）。
