# 2026-06-15 — 管道流动悬停效果

## 本轮需求

以底部管道为入口、红色管道为出口，沿模型内置路径制作流动视觉效果，鼠标悬停在模型上时触发。

## 设计方案

- 复用 GLB 内建节点 `流动模型`（作者预留的流动路径网格）与 `IN_\` / `OUT_\` 进出口标记
- 默认隐藏 `流动模型`，悬停时用半透明蓝色条纹着色器叠加显示
- `Raycaster` 检测鼠标是否命中 `modelRoot` 可见网格，命中则淡入流动层
- 流动方向按网格局部 Y 轴（由底部入口向上至红色出口）驱动 UV 动画

## 实现要点

- 新增 `src/flowEffect.js`：`setupFlowEffect` 创建 overlay + 着色器 + 悬停逻辑
- `main.js` 在模型加载、缩放、取景后初始化流动效果，并在 `animate` 中 `update(delta)`

## 遇到的问题及解决

- 模型无动画轨道，流动完全由自定义 Shader `uTime` 驱动
- `流动模型` 使用 Draco 压缩，与主模型一同由 `DRACOLoader` 解码
