# 复杂技能模块 — 第一段落地

## 本轮需求

对照 `docs/九宫牌局复杂技能模块三段开发计划.md` 第一段，以及权威设计文档 `九宫牌局/04-技能/技能系统.md`、`01-机制规则/战斗机制.md`，落地统一结算链与事件底座，并用代表性技能验证。

## 设计方案

### 新增层次

| 模块 | 职责 |
|------|------|
| `BoardActionResolver` | 统一承接三类九宫格互动后的结算链 |
| `SkillRuntime` | 按移动/移除事件分发怪物技能 |
| `CardRuntime` | 卡牌移动计数、战斗计数、uid 生成 |
| `MoveReason` | 区分系统旋转与技能换位 |

### 结算链顺序（对齐战斗机制.md）

```
玩家动作 → 直接效果 → killMonster / removeCard
  → 补牌 → 旋转(若需要) → 移动触发技能
  → 派生战斗(不休追击，不额外旋转)
  → 二次补牌 → 通关检查 → 解锁输入
```

### killMonster vs removeCard

- `killMonster`：血量归零击杀；发金币、精英奖励、遗物 `[击杀怪物时]`
- `removeCard`：任意卡离场；触发 `[被移除时]` 技能（如散架、尖石）
- 顺序：`killMonster` → `removeCard`（与技能系统.md 事件顺序一致）

### 输入锁

- 新增 `isActionResolving`，覆盖整条结算链
- 玩家动作开始锁定，移动触发与二次补牌结束后解锁

## 实现要点

1. `GridManager.rotateGrid` 返回 `{ card, cardData, fromSlot, toSlot, reason }` 移动记录
2. `GridManager.swapSlotsInstant` / `moveCardInstant` 供技能换位
3. `shuffleCardToDeck` 改为随机插入（对齐「洗入战斗卡组」语义）
4. 三类入口统一：
   - 点击怪物击杀 → `BattleResolver` → `runSettlementChain({ shouldRotate: true })`
   - 拾取帮助卡 → `removeCard` → `runSettlementChain({ shouldRotate: true })`
   - 点击相邻空格 → `runSettlementChain({ shouldRotate: true })`
5. 代表性技能（TestData）：
   - **散架**（大骷髅）：`onRemove` + `spawnToDeck`
   - **不稳定**（摇晃骷髅）：`onMoveEveryN` + `swapRandomMonster`
   - **不休追击**（追猎兽人）：`onMoveToPlayerAdjacent` + `autoBattle`（派生战斗不旋转）
   - **空中打击**（空中巨眼）：`onMoveToSlot` 格 1/3/7/9 对玩家 2 伤

## 遇到的问题及解决

- **原 `handleMonsterDeath` 内联 onRemove**：尖石等与击杀混在同一函数，散架无法与金币规则解耦 → 拆到 `removeCard` + `SkillRuntime.processRemoveSkillEffects`
- **旋转不产生移动事件**：`rotateGrid` 回调现携带 moveRecords，供 `SkillRuntime` 计数与触发
- **派生战斗递归**：`MAX_CHAIN_DEPTH = 32`；`isDerived` 战斗走 `continueAfterDerivedBattle`，不重新旋转
