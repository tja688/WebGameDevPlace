# 复杂技能模块 — P0/P1 落地修复汇报

## 本轮需求
1. 修复 P0：帮助卡击杀怪物、遗物 `onKill.aoe_damage` 击杀旁路未走 `boardResolver.killMonster`，导致漏触发 `onRemove`/金币规则不一致。
2. 修复 P0：正常补牌路径未触发 `processEnterSkillEffects`（`onEnter` 只在测试关卡放置触发）。
3. 修复 P0：战斗 action `armorLossDmg`、`atkPerDamage` 未接线（`processCombatSkillEffects` 未处理）。
4. 修复 P1：`rotateBoard` 的异步 `rotateGrid` 回调导致移动派生丢失（额外移动记录无法同步收集）。
5. 修复 P1：`嘲讽` 的战斗目标限制缺失；`和我打！` 缺少“强制战斗”语义。

## 设计方案（对齐现有主干）
- “击杀必须走一等概念”：统一改为调用 `BoardActionResolver.killMonster`，让 `killMonster -> 触发 onKill -> removeCard -> processRemoveSkillEffects` 成为唯一语义入口。
- “登场必须由补牌统一触发”：把 `processEnterSkillEffects` 下沉到 `GridManager._refillStep`，确保所有补牌来源一致触发。
- “战斗技能分两段落地”：`processCombatSkillEffects` 只负责解析技能意图并输出标记；真正依赖动态量（护甲损失/实际造成伤害）的落地放在 `BattleResolver` 中。
- “异步旋转必须可等待”：将 `processMoveSkillEffects` 改为 `async`，在 `rotateBoard` 时等待 `rotateGrid` 的 moveRecords，再进入下一轮派生移动链。

## 实现要点
### P0：击杀旁路收敛
- `src/systems/HelpCardEffects.js`
  - `effect.type === "damage"` 与 `effect.type === "aoe_damage"` 中死亡分支改为调用 `scene.boardResolver.killMonster(slot, container, { reason, wasKilledBy, animate:false })`。
  - 删除了原先的直改金币/直 destroy/直 emit `MONSTER_KILLED` 等旁路逻辑。
- `src/systems/RelicManager.js`
  - `onKill.aoe_damage` 改为在死亡时调用 `boardResolver.killMonster`，并在结算前按同一伤害模型计算护甲损失与血量损失。

### P0：补牌触发 onEnter
- `src/grid/GridManager.js`
  - 在 `_refillStep` 填充 `slotContents` 后、发出 `GameEvents.SLOT_FILLED` 之前调用 `this.scene.boardResolver.processEnterSkillEffects(slotIndex, card)`。
- `src/systems/BoardActionResolver.js`
  - 增加 `processEnterSkillEffects(slot, container)` 方法，内部调用 `SkillRuntime.processEnterSkillEffects`。

### P0：战斗 action 接线
- `src/systems/SkillRuntime.js`
  - `processCombatSkillEffects` 增加输出字段：
    - `armorLossDmg`（条件匹配左列）
    - `atkPerDamageAmount`
  - `armorLossDmg` / `atkPerDamage` 不直接做动态量计算，由 `BattleResolver` 落地。
- `src/battle/BattleResolver.js`
  - `applyDamage` 改为返回 `{ armorLoss, hpLoss, rawDmg }`。
  - 在玩家打掉怪物护甲后：若启用 `armorLossDmg`，对玩家再额外造成等量伤害（`armorLoss`）。
  - 在怪物造成伤害后：用 `takeDamage` 返回的实际扣血量按 `atkPerDamageAmount` 换算攻击增量并刷新卡面展示。

### P1：rotateBoard 异步收集修复
- `src/systems/SkillRuntime.js`
  - `processMoveSkillEffects` 改为 `async`。
  - `onMoveEveryN + rotateBoard` 时用 `await new Promise(resolve => grid.rotateGrid({..., onComplete: resolve }))` 收集 moveRecords，保证派生移动链不丢失。
- `src/systems/BoardActionResolver.js`
  - `_processMoveChain` 中对 `processMoveSkillEffects` 使用 `await`，让异步旋转在进入下一层链路前完成。

### P1：嘲讽/和我打！语义修复
- `src/systems/SkillRuntime.js`
  - `runDerivedAutoBattles`：当玩家正交相邻格存在 `skill.id === "taunt"` 的怪物时，只允许派生自动战斗打该嘲讽目标。
- `src/scenes/GameScene.js`
  - 玩家手动点击战斗时：若相邻存在嘲讽怪物，则其它怪物点击无效（只能与嘲讽怪物开战）。
- `src/data/TestData.js`
  - 给 `skill.id === "fightMe"` 的 `和我打！` 补上 `{ event:"onMoveToPlayerAdjacent", action:"autoBattle" }`，实现“强制战斗”触发。

## 遇到的问题及解决
1. **rotateBoard 丢派生移动**：原实现把 `rotateGrid` 的 moveRecords 通过 `onComplete` 回调 push 到 `extraMoves`，但回调发生在当前 `_processMoveChain` 返回之后，导致派生链提前结束。
   - 解决：让 `processMoveSkillEffects` `await` 旋转完成，再把 moveRecords 同步加入派生链。
