# New Web Game Dev

Read `README.md` before doing any work.

## Workflow

1. Choose a stable project folder name.
2. Create the project documentation root at:
   `C:\Users\jinji\Documents\GitHub\WebGameDevPlace\WebGameDev Docs\<project-folder>\`
3. Create these subfolders:
   - `dev plan`
   - `reference document`
4. Create the initial dev-plan note in `dev plan/`.
5. Create the initial reference note in `reference document/`.
6. Create the project entry under `src/playgrounds/`.
7. Register the project in the project registry.

## Required Outputs

- One new project folder under `WebGameDev Docs/`
- One initial dev-plan note
- One initial reference-document seed note
- One new project entry under `src/playgrounds/`

## Naming Rules

- Use a stable project folder name that can remain valid long term.
- Keep `dev plan` and `reference document` exactly spelled this way.
- The initial dev-plan file should use: `YYYY-MM-DD - initial project setup.md`

## Guardrails

- Do not recreate public templates or template browsing UI.
- Treat runtime as technical metadata, not the public organizing model.
- Follow the current app routes and project registry contract from `README.md`.
