# 卡牌地下城 - 重构版 v4.9

> 纯前端网页游戏，全部核心逻辑采用**纯对象 + 纯函数**，为后续 Unity 迁移提供最小摩擦的代码基座。

## 快速开始

项目使用 ES Modules，必须通过 HTTP 服务访问，不能直接用 `file://` 打开 `index.html`。

```bash
node serve.js
```

启动后访问 `http://localhost:8080`。

Windows 上也可双击 `dev.bat`，它会检查 Node.js 与 8080 端口，并打开本地页面。

## 架构概览：为 AI 翻译而设计

本项目遵循三条核心原则，确保 Web 代码对 AI 足够清晰，未来迁移 Unity 时可直接翻译：

### 原则 1：数据置顶（Data on Top）

所有卡牌、敌人、效果、Buff 的定义均为顶层纯对象常量，不埋在函数或 DOM 操作里。

```javascript
// js/data/cards.js
export const CARD_DEFS = {
  fireball: {
    id: 'fireball',
    name: '火球术',
    baseValue: 10,
    keywords: ['grow'],
    rarity: 'white'
  }
};
```

### 原则 2：效果用"配置 + 工厂"，不用类继承

效果系统无 `class`、无 `Map`、无 `Set`。效果处理器是纯对象，注册到全局触发器表。

```javascript
// js/effects/play.js
registerEffect({
  id: 'grow',
  triggers: 'on_play',
  priority: 700,
  condition: (ctx) => ctx.card.keywords.includes('grow'),
  execute: (ctx) => {
    ctx.card.permanentBonus += 1;
  }
});
```

触发时按 `trigger -> priority` 排序执行：

```javascript
// js/systems/board.js
FX.fire(Trigger.ON_PLAY, createEffectContext({ state, trigger, card, slotIndex }));
```

### 原则 3：状态保持"JSON 可打印"

战斗状态（player、enemies、hand、deck、slots 等）全部为纯对象/数组，无闭包、无 DOM 引用。

```javascript
let state = {
  screen: 'battle',
  phase: 'playing',
  player: { name: '老兵', maxHearts: 3, hearts: 3 },
  monster: { name: '荒原狼', maxHp: 150, hp: 150, ... },
  slots: [
    { index: 0, multiplier: 1, cards: [] },
    { index: 1, multiplier: 1, cards: [] },
    { index: 2, multiplier: 1, cards: [] }
  ],
  hand: [...],
  deck: [...],
  discard: [],
  turn: 1,
  effectTimeline: [],
  timelineSeq: 0
};
```

`effectTimeline` 是纯 JSON 结算时间线，用于记录出牌入格、效果开始/结束、抽牌、伤害、清场和下一回合开始等顺序事实。Web 端仍即时结算；未来 Unity 端可按该时间线插入动画等待点，避免动画层重排结算顺序。

## 当前玩法事实

核心循环：

```text
战斗 -> 牌店/铁匠 -> 随机事件 -> 下一场战斗
```

战斗目标是在出牌回合内通过卡牌点数、倍率格和计策削减怪物血量。怪物血量归零则胜利；人群数归零则失败。老兵初始装备"战场经验"提供首回合多抽一张牌。

基础战斗参数：

| 项目 | 当前实现 |
|---|---|
| 倍率格 | 固定 3 格，初始均为 1X |
| 放牌规则 | 所有卡牌都可在任意倍率格无限堆叠 |
| 每回合抽牌 | 5 张 |
| 手牌上限 | 10 张 |
| 回合失败代价 | 未击杀时失去 1 人群 |
| 战后恢复 | 战斗结束后人群恢复至上限 |
| 货币 | 金币 |

已验证怪物特性：

| 怪物 | 当前实现 |
|---|---|
| 人面草 | 香甜诱饵：打出在中间格的卡牌永久 +1；盘根：每回合少抽 1 张牌 |
| 骷髅骑士 | 亡者：所有卡牌最终点数 -2；惊人伟力：无计策时倍率格点数 -10；武技：记录上回合生效计策，复现时倍率格点数 -5 |
| 黄色君王 | 黄之王：禁用奉献；黄色领域：无奉献卡牌在同格触发反向奉献；黄之心：回合开始优先给尚无奉献的随机手牌赋予奉献 |

伤害公式：

```text
单格伤害 = 该格所有卡牌最终点数之和 * 该格当前倍率点数
总伤害 = 所有倍率格伤害之和 * 额外指数
```

## 计策系统

计策只在三个倍率格的卡牌数量精确满足二版设计表时生效。条件不满足时，当前计策立即清空，不保留上一轮加成。

已实现基础计策：尝试推进、左侧强袭、右侧强袭、中线强袭、稳重推进、计划左攻、计划右攻、计划中攻、强硬推进。

已实现超限计策：超限推进、超限左攻、超限右攻、超限中攻。

计策强化等级保存在 `runData.strategyLevels`，商店与事件可提升随机计策等级。

战斗界面左侧中部固定显示计策阵型表，实时展示当前三格堆叠、命中的计策与倍率格加成，不再依赖一闪而过的中心提示确认阵型。

## 词条系统

当前词条以二版设计为准：

| 词条 | 触发时机 | 当前实现 |
|---|---|---|
| 伟力 | 最终点数计算 | 本牌点数无条件翻倍 |
| 回响 | 打出时 | 本牌其他打出时效果再执行一次 |
| 奉献 | 在场上时 | 下一张打出在同倍率格的卡牌获得本牌当前点数一半，向下取整，只触发一次 |
| 连携 | 打出时 | 抽 1 张牌；`连携2` 抽 2 张 |
| 双生 | 打出时 | 复制一张本牌加入手牌，复制体移除双生词条并标记为衍生牌 |
| 留场 | 回合结束 | 本牌继续留在倍率格，不进入弃牌堆 |
| 蔓延 | 打出时 | 将 0 点扩散牌加入手牌 |
| 成长 | 打出时 | 本牌永久 +1；成长2 为永久 +2 |
| 保留 | 回合结束 | 本牌留在手牌，不进入弃牌堆 |
| 合群 | 在场上时 | 相邻倍率格每有一张其他卡牌，本牌点数 +1 |
| 齐心 | 在场上时 | 同倍率格每有一张其他卡牌，本牌点数 +1 |

词条结算顺序：**在场上时 > 打出时 > 回合结束**

衍生牌规则：双生和蔓延生成的卡牌只用于当前战斗或 Playground 当前测试轮，不会写回永久牌组。

训练体系专属效果：

| 卡牌 | 当前实现 |
|---|---|
| 训练痕迹 | 已在倍率格后，相邻倍率格后续打出的成长效果多触发一次 |
| 猛训练 | 已在倍率格后，同倍率格后续打出的成长效果多触发一次 |
| 集体训练 | 已在倍率格后，同倍率格后续打出的卡牌获得成长2 |

## Playground 与 AI 后门

Playground 从主界面按钮进入，包含两个用途：

| 模式 | 用途 |
|---|---|
| 词条效果测试 | 使用 `js/playground/scenario-data.js` 中的预设场景批量验证词条 |
| 对战测试场 | 复用真实战斗渲染与输入，可切换怪物、重置血量、清空格子、添加手牌、编辑卡牌/怪物数值 |

Playground 对战测试场与正式主线战斗状态隔离：测试场结束后会自动重置怪物血量与人群数，正式主线战斗仍按正常奖励/失败流程结算。

事件中的"立即打怪/挑战精英"战斗也与后续正式主线战斗状态隔离。

正式冒险战斗右侧提供轻量调试面板，仅用于玩家侧交互测试：切换并添加任意卡牌到手牌、模拟抽 1 张、回满人群、直接结算胜利；不提供怪物切换或怪物参数控制。

卡牌奖励三选一按白/蓝/金 65%/30%/5% 权重生成。商店、铁匠和可疑商人遗物按低/中/高 65%/30%/5% 权重生成；出土遗物默认提供中级遗物，并按高级遗物 5% 概率逐项替换。

数据覆盖系统使用 `localStorage` key `card_dungeon_data_overrides`。参数配置面板中的卡牌和怪物数值修改会即时应用，并在浏览器会话间保留。

浏览器控制台可用：

```javascript
await AITest.run('mighty_basic');   // 运行单个场景
await AITest.runAll();               // 运行所有场景
await AITest.report();               // 生成完整测试报告
await AITest.quickTest({ keywords: ['mighty'], baseValue: 5 }); // 快速验证
AutoTest.autoPlayOptimal();          // 自动出牌
godMode();                           // 上帝模式
simulateBattles(100);                // 模拟 100 场自动战斗
```
