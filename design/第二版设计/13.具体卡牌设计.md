### 13.2 生长体系

| 卡牌名称 | 点数  | 词条  | 效果                                                                    | 稀有度 | 定位   | 说明    |
| ---- | --- | --- | --------------------------------------------------------------------- | --- | ---- | ----- |
| 战时训练 | 8   | 成长2 |                                                                       | 白卡  | 垃圾核心 | 基础生长牌 |
| 训练痕迹 | 0   |     | 若本牌已在倍率格，则打出在相邻两侧倍率格卡牌的成长效果多触发一次（例1：成长2，就变为成长4 例2：成长4，就变成成长8）         | 白卡  | 优质核心 |       |
| 猛训练  | 10  |     | 若本牌已在倍率格，则后续打出在同倍率格卡牌的成长效果多触发一次（例1：成长2，就变为成长4 例2：成长4，就变成成长8）          | 蓝卡  |      |       |
| 集体训练 | 20  |     | 若本牌已在倍率格，则后续打出在同倍率格的卡牌获得成长2（例1：打出集体训练，后续打出了两张蛮力，则无其他因素干扰下两张蛮力点数永久成长2） | 金卡  |      |       |
