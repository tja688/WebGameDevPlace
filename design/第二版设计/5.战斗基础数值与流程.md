### 5.1 基础参数

| 参数        | 数值  | 说明                                            |
| --------- | --- | --------------------------------------------- |
| 初始生命（人群数） | 3   | 代表剩余出牌回合数，一共能出三次牌                             |
| 每回合抽牌     | 5张  | 战斗开始时及每回合开始时抽取                                |
| 手牌上限      | 10张 | 回合结束丢弃所有无[[保留]]词条卡牌                           |
| 牌桌格子      | 3格  | 初始所有倍率格均为1X                                   |
| 牌组        | 无上限 | 回合开始时，将所有弃牌堆，卡牌重新洗回牌库，其他情况下在牌库用完后，弃牌堆牌组不会洗回牌组 |


### 5.2 战斗流程

#### 回合流程

```
1. 回合开始
   └─ 将所有弃牌堆，卡牌重新洗回牌库
   └─ 抽5张牌

2. 玩家出牌阶段
   └─ 从手牌选择一张卡牌，指定倍率格打出
   └─ 结算卡牌效果与点数
   └─ 更新牌桌状态
   └─ 回到"从手牌选择一张卡牌，指定倍率格打出"并重复出牌流程,直到玩家停止出牌
   └─ 计算目前牌桌排列是否符合某一计策类型
   └─ 玩家可主动结束回合

3. 回合结束判定
   └─ 计算牌桌堆叠顺序是否符合计策类型
      └─ 若符合某一计策类型 ：将加成效果提供的倍率格点数增加到倍率格点数上
      └─ 若不符合任意计策类型：不提供任何加成效果
   └─ 计算牌桌总伤害 = Σ(各倍率格卡牌最终点数之和 × 各倍率格点数) x 额外指数
   └─ 若总伤害 ≥ 怪物血量：战斗胜利，进入奖励结算
   └─ 若总伤害 < 怪物血量：怪物血量扣除牌桌总伤害点数，玩家损失1人群（受怪物技能影响可能多扣）
      ├─ 若人群数 > 0：清空牌桌（【留场】牌保留），丢弃所有剩余卡牌（带有保留词条卡牌不丢弃），复原所有临时数值增减，开启下一回合
      └─ 若人群数 = 0：战斗失败，本局游戏结束
```

#### 单张卡牌结算顺序

当一张卡牌被打出到指定格子时：

```
1. 卡牌从手牌移至目标倍率格
2. 结算牌桌上已有的倍率格光环效果
3. 结算卡牌自身效果
4. 确定该卡牌最终点数
5. 卡牌留在牌桌上，等待回合结束总伤害结算
```

#### 回合结束伤害结算

```
1. 遍历每个有卡牌的倍率格
2. 倍率格伤害 = 该格所有卡牌点数之和 × 该倍率格点数
3. 总伤害 = 所有倍率格伤害之和 x 额外指数
4. 比较总伤害与怪物血量
