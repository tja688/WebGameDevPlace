### 3.2 倍率格规则

| 规则       | 说明                                           |
| -------- | -------------------------------------------- |
| **堆叠规则** | 倍率格上能够打出无上限的卡牌[[堆叠]]                         |
| **数值叠加** | 同倍率格多张卡牌堆叠，结算时所有卡牌点数相加乘以倍率格点数                |
| **回合结束** | 非[[留场]]牌全部进入弃牌堆，倍率格清空                        |
| **倍率上限** | [[倍率格]]可无限升级，无上限                             |
| **计策**   | 当三个倍率格上的卡牌以特定顺序堆叠排列并满足[[计策]]要求后，将该计策加成提供给倍率格 |

### 3.3 伤害计算公式

```
单倍率格伤害 = 该倍率格所有卡牌最终点数和 × 该倍率格当前点数
总伤害 = Σ(各倍率格伤害) x 额外指数
```

- **示例**：格2倍率为3X，放置点数5的卡牌，该倍率格伤害 = 5 × 3 = 15
- **示例2**：格2倍率为3X，放置一张点数5的卡牌和一张点数4的卡牌，该倍率格伤害 = （5+4） × 3 =27
