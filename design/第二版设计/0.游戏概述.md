| 项目       | 内容                                                              |
| -------- | --------------------------------------------------------------- |
| **游戏类型** | 回合制卡牌策略 Roguelike                                               |
| **核心玩法** | 抽牌 → 打出卡牌至倍率格 →堆叠卡牌凑成计策提供倍率格点数→卡牌点数×倍率格点数  → 削减怪物血量归零 →    击败怪物 |
| **灵感来源** | 《杀戮尖塔》和《大巴扎》爬塔构筑 + 《小丑牌》点数乘倍率桌玩法                                |
| **核心循环** | 战斗 → 进入牌店→构筑卡组 → 选择随机事件 → 下一场战斗                                 |
| **胜利条件** | 三个出牌回合结束后， 怪物血量归零                                               |
| **失败条件** | 人群数（生命值）归零（三次出牌次数耗尽）                                            |
