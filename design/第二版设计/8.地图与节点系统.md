### 8.1 地图结构

游戏共**三大层**，每层包含8个节点**。打完BOSS后进入下一层，从新的普通怪开始。

**第一层（1-1 至 1-8）节点配置：**

| 节点  | 类型               | 胜利后奖励                           |
| --- | ---------------- | ------------------------------- |
| 1-1 | 1-1数值普通怪（3种随机1种） | 商店 → 高概率常见事件池二选一                |
| 1-2 | 1-2数值普通怪（3种随机1种） | 商店 → 高概率常见事件池二选一                |
| 1-3 | 1-3数值普通怪（3种随机1种） | 商店 → 高概率常见事件池二选一                |
| 1-4 | 精英怪（3种随机1种）      | 铁匠 → 中概率稀有事件池三选一                |
| 1-5 | 1-5数值普通怪（3种随机1种） | 商店 → 低概率稀有事件池二选一                |
| 1-6 | 1-6数值普通怪（3种随机1种） | 商店 → 低概率稀有事件池二选一                |
| 1-7 | 1-7数值普通怪（3种随机1种） | 商店 → 低概率稀有事件池二选一                |
| 1-8 | BOSS（3种随机1种）     | BOSS遗物三选一 → 低概率传说事件池三选一 → 进入2-1 |

- **第二层（2-X）**：参照第一层设计，数值提升
- **第三层（3-X）**：参照第一层设计，数值进一步提升
- **永久成长**：跨层保留卡组、强化、遗物、格子倍率、生长加成

### 8.2 选路机制

- 解决完当前房间后，才能看到后续房间的选项
- 地图左侧显示即将面对的精英怪和BOSS名称，便于玩家调整卡组
- 任意普通战斗房后均会获得一次**商店**购物机会
- 任意精英战斗房后均会获得一次**铁匠**购物机会
- 任意BOSS战斗房后均会获得一次**BOSS装备三选一**机会

### 8.3 房间类型

| 房间类型        | 说明                      |
| ----------- | ----------------------- |
| **普通战斗房**   | 普通战斗，胜利后获得魂+三选一卡牌       |
| **精英战斗房**   | 精英战斗，难度更高，胜利后获得更多魂+更好奖励 |
| **BOSS战斗房** | 每层最终战斗，胜利后解锁牌桌格子+BOSS遗物 |
| **商店**      | 购买卡牌、遗物、删牌、强化卡牌         |
| **铁匠房**     | 升级格子倍率、购买遗物、词条附魔        |
| **事件房**     | 随机事件，地图显示事件名称，资深玩家可预判效果 |
